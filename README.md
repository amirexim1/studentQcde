# سیستم پیگیری مطالعه با قابلیت شخصی‌سازی کامل

یک وبسایت کامل برای ثبت و پیگیری مطالعه با امکان داشتن برنامه کلاسی، آزمون، تکلیف، مدیتیشن و گزارش عملکرد به همراه ربات تلگرامی.

## ✨ ویژگی‌های جدید

### 🎨 شخصی‌سازی کامل ظاهر
- **۵ تم رنگی مختلف**: آبی، سبز، نارنجی، قرمز، بنفش
- **۳ فونت فارسی حرفه‌ای**: وزیرمتن، شبنم، لاله‌زار
- **حالت تاریک/روشن** (Dark/Light Mode)
- **ذخیره تنظیمات** در مرورگر کاربر
- **انیمیشن‌های جذاب** و افکت‌های هاور

### 📱 رابط کاربری پیشرفته
- استفاده از **Font Awesome 6** برای آیکون‌ها
- طراحی **ریسپانسیو** و موبایل‌فرندلی
- **کارت‌های آماری** با انیمیشن
- **نمودارهای تعاملی** با Chart.js
- **تبدیل اعداد به فارسی**

### 🤖 ربات تلگرامی
- اتصال اکانت تلگرام به وبسایت
- ثبت سریع جلسات مطالعه و مدیتیشن
- مشاهده برنامه روزانه و آمار هفتگی
- مدیریت آزمون‌ها و تکالیف

## 🚀 راه‌اندازی

### پیش‌نیازها
- Python 3.8+
- MySQL Database
- Telegram Bot Token (اختیاری برای ربات)

### نصب محلی

1. کلون کردن پروژه:
```bash
git clone <repository-url>
cd study-tracker
```

2. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

3. تنظیم متغیرهای محیطی:
```bash
export DATABASE_URL="mysql+pymysql://user:password@localhost/dbname"
export SECRET_KEY="your-secret-key-here"
export TELEGRAM_BOT_TOKEN="your-bot-token"  # اختیاری
```

4. اجرای وبسایت:
```bash
python app.py
```

5. اجرای ربات تلگرام (اختیاری):
```bash
python bot.py
```

- `users`: اطلاعات کاربران
- `study_sessions`: جلسات مطالعه
- `class_schedules`: برنامه کلاسی هفتگی
- `exams`: آزمون‌ها
- `assignments`: تکالیف
- `meditation_sessions`: جلسات مدیتیشن
- `telegram_links`: اتصال تلگرام به کاربران

## 🎯 امکانات وبسایت

### صفحه اصلی
- معرفی ویژگی‌ها
- انتخاب تم رنگی و فونت
- دکمه‌های ورود و ثبت‌نام

### داشبورد
- آمار کلی (جلسات، دقایق مطالعه، آزمون‌ها، تکالیف)
- آخرین جلسات مطالعه
- آزمون‌های پیش‌رو
- تکالیف در انتظار
- آخرین مدیتیشن‌ها
- نمودار مطالعه هفتگی

### ثبت مطالعه
- فرم ثبت جلسه مطالعه
- انتخاب درس، موضوع، مدت زمان

- جدول هفتگی کلاس‌ها

- نمایش محل و ساعت کلاس

### آزمون‌ها
- لیست آزمون‌های پیش‌رو
- ثبت آزمون جدید
- مشخص کردن نوع آزمون
- وضعیت آماده‌سازی

### تکالیف
- مدیریت تکالیف
- تعیین مهلت تحویل
- علامت‌گذاری انجام شده

### مدیتیشن
- ثبت جلسات مدیتیشن
- انواع مختلف مدیتیشن
- پیگیری زمان مدیتیشن

### گزارش عملکرد
- نمودارهای پیشرفته
- آمار تفکیک شده
- خروجی گرفتن از داده‌ها

## 🤖 دستورات ربات تلگرام

- `/start`: شروع ربات
- `/link username`: اتصال اکانت تلگرام به وبسایت
- `/study subject duration topic`: ثبت جلسه مطالعه
- `/meditate type duration`: ثبت مدیتیشن
- `/today`: مشاهده برنامه امروز
- `/stats`: آمار هفتگی
- `/exams`: لیست آزمون‌ها
- `/assignments`: لیست تکالیف
- `/help`: راهنما
